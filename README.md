# Проект new_diary

## Описание:

Проект new_diary - это веб-приложение для ведения личного дневника.

## Стек используемых технологий (библиотек):
+ Python 3.12.10
+ poetry
+ django 6.1.1
+ dotenv 0.9.9
+ pillow 12.3.0
+ psycopg-2-binary 2.9.13
+ python-dotenv 1.2.3
Все контроллеры имеют способ определения и обработки представлений в Django с помощью классов(метод CBV).

## Установка:

1. Клонируйте репозиторий:
    ```
     https://github.com/ViktorPilot/new_diary.git
    ```
2. Запустите PyCharm у себя на компьютере.
3. Откройте скачанный репозиторий в PyCharm.
4. Создайте виртуальное окружение командой `poetry install`.
5. Активируйте ВО командой `poetry env activate`.
6. Установите зависимости командой `poetry init`.
7. Программа готова к работе.

## Запуск локального сервера:

1. Для запуска локального сервера у себя на компьютере необходимо в терминале ввести команду:
`python manage.py runserver 8000`(для Windows), `python3 manage.py runserver 8000`(для Unix-систем), 
где крайним значением указан порт запускаемого сервера.

## Порядок работы со страницами браузера приложения `note`:

1. В браузере перейти на страницу с адресом `127.0.0.1:8000/home/`, которая является главной страницей приложения.
Если пользователь авторизован, отобразятся текущие заметки личного дневника. Если пользователь не авторизован, 
произойдет перенаправление на страницу входа в аккаунт.
2. Для создания новой заметки, нажать на `новая запись`, заполнить поля, подтвердить создание.
   + при успешном добавлении заметки в базу данных происходит переход на страницу с созданной заметкой.
3. Для выбора заметок по году и месяцу создания нажать на интересующий год и месяц.
4. Для просмотра подробных данных о заметке нажать на `подробнее` в карточке заметки.
5. Для редактирования существующей заметки нажать на `редактировать` в карточке заметки, изменить данные в полях, 
подтвердить изменение.
   + при успешном редактировании заметки в базе данных происходит переход на страницу с отредактированной заметкой.
6. Для удаления существующей заметки нажать на `удалить` в карточке заметки, подтвердить удаление.
   + при успешном удалении заметки из базы данных происходит переход на главную страницу.
7. Для поиска заметок по заголовку или содержимому ввести ключевые слова в поле, нажать `найти`. При выборе года
и месяца поиск будет осуществляться с учетом фильтра.
8. Для добавления заметок в базу данных необходимо перейти в админку по адресу `127.0.0.1:8000/admin/`, 
ввести учетные данные. После входа выбрать `add заметка` заполнить поля информации, далее выбрать `save`.


## Порядок работы со страницами браузера приложения `users`:

1. Для регистрации нового пользователя:
   + в браузере перейти на страницу входа в аккаунт `127.0.0.1:8000/users/login/`(в случае попытки перехода 
   неавторизованного пользователя на страницы приложения произойдет автоматическое перенаправление на страницу 
   входа в аккаунт);
   + нажать `зарегистрироваться`;
   + заполнить поля регистрации, подтвердить регистрацию;
   + при успешной регистрации произойдет отправка приветственного письма на email пользователя и автоматический переход 
   на страницу входа в аккаунт;
   + в случае ввода невалидных данных появится сообщение об ошибке.
2. Для входа в аккаунт необходимо на странице входа в аккаунт заполнить поля `email`, `password`и нажать `Войти`. 
   + при успешной авторизации произойдет переход на главную страницу списка заметок.
   + в случае ввода невалидных данных появится сообщение об ошибке.
3. Для выхода из аккаунта необходимо на страницах приложения открыть вкладку `email пользователя` на навигационной панели, 
выбрать `Выйти`, после чего произойдет переход на страницу ввода логина и пароля.
4. Для удаления аккаунта необходимо на страницах приложения открыть вкладку `email пользователя` на навигационной панели, 
выбрать `Удалить`, после чего произойдет переход на страницу ввода логина и пароля.
5. Аутентифицированные пользователи имеют возможность добавлять, изменять и удалять свои заметки. Не аутентифицированные 
пользователи при попытке перейти на страницы приложения перенаправляются на страницу ввода логина и пароля.
